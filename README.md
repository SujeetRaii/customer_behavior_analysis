# 👨🏻‍💻 Customer Behavior Data Analyst Portfolio Project

This project is an end-to-end **Data Analytics Portfolio Project** focused on analyzing customer purchasing behavior and generating actionable business insights.

The project covers the complete analytics workflow using **Python, SQL, and Power BI**, from data cleaning and exploration to SQL-based analysis and interactive dashboard creation.

## 📌 Project Overview

The objective of this project is to analyze customer shopping behavior and identify patterns related to:

- Customer demographics
- Purchasing behavior
- Customer segmentation
- Product performance
- Discounts and purchasing patterns
- Subscription behavior
- Shipping preferences
- Customer loyalty
- Revenue contribution

The project demonstrates how raw customer data can be transformed into meaningful business insights using multiple data analytics tools.

## 🛠️ Tools & Technologies

- **Python** – Data cleaning, preprocessing and exploratory data analysis
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **SQL / MySQL** – Business analysis and querying
- **Power BI** – Interactive dashboards and visualization
- **Excel / CSV** – Data source and initial data handling

## 🔄 Project Workflow

### 1. Data Preparation & Exploratory Data Analysis – Python

The raw customer dataset is first analyzed and prepared using Python.

Tasks include:

- Importing the dataset
- Understanding the structure of the data
- Checking data types
- Identifying missing values
- Handling missing and inconsistent data
- Data cleaning and transformation
- Creating derived columns
- Performing exploratory data analysis

### 2. Data Analysis – SQL

The cleaned data is analyzed using SQL to answer important business questions.

Analysis includes:

- Revenue by gender
- Customers spending above average
- Top-rated products
- Average purchase amount by shipping type
- Subscriber vs. non-subscriber spending
- Discount usage by product
- Customer segmentation
- Top products within each category
- Repeat buyer subscription behavior
- Revenue by age group

### 3. Data Visualization – Power BI

The analyzed data is used to create an interactive Power BI dashboard.

The dashboard focuses on:

- Total revenue
- Total customers
- Average purchase amount
- Customer demographics
- Product performance
- Customer segments
- Subscription status
- Discount behavior
- Shipping preferences
- Revenue trends and comparisons

Interactive filters and slicers are used to allow users to explore the data from different perspectives.

### 4. Business Insights & Recommendations

The final stage focuses on converting analytical findings into meaningful business insights.

The analysis can help identify:

- High-value customer segments
- Products with strong customer demand
- Products frequently purchased with discounts
- Differences between subscribers and non-subscribers
- Customer loyalty patterns
- Revenue-driving customer groups
- Opportunities for improving customer retention and subscription adoption

## 📊 SQL Business Questions

Some of the key questions answered in the project include:

1. What is the total revenue generated by male vs. female customers?
2. Which customers used a discount but still spent more than the average purchase amount?
3. Which products have the highest average review rating?
4. How does average purchase amount differ between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which products have the highest percentage of discounted purchases?
7. How many customers belong to New, Returning, and Loyal segments?
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?
